# 요구사항 정의서 v2

> 최종 업데이트: 2026-03-18

## 서비스 컨셉

**"매일 찾아오는 나만의 심리상담사"**

사용자가 매일 편하게 찾아와 AI 챗봇과 심리상담을 하고, 대화 맥락에 맞는 콘텐츠(영상, 도서 등)를 추천받는 서비스. AI 챗봇이 서비스의 메인이며, 나머지는 부가 서비스로 위치한다.

---

## 사용자 플로우 (메인)

```
① 첫 방문
   └─ 회원가입 (이메일 + 비밀번호, 암호화)

② 재방문
   └─ 로그인

③ 메인 화면 = AI 챗봇
   ├─ [오늘의 상태 체크] (매일 첫 접속 시)
   │   ├─ "오늘 기분은 어떠세요?" → 감정 선택 (좋아요/보통/우울/불안/화남/지침)
   │   ├─ "어젯밤 잠은 잘 주무셨어요?" → 수면 상태
   │   └─ "요즘 스트레스는 어떠세요?" → 스트레스 수준
   │
   ├─ [AI 맞춤 첫 대화]
   │   └─ 상태 체크 결과 기반으로 공감 + 탐색 질문
   │       예: "오늘 기분이 우울하시군요. 혹시 특별한 일이 있으셨나요?"
   │
   ├─ [상담 대화 진행]
   │   └─ 자유 대화 (공감 중심, 비지시적 상담)
   │
   └─ [콘텐츠 추천] (대화 맥락 기반, 적절한 시점에)
       ├─ "이 영상이 도움이 될 것 같아요" → YouTube 링크 (카드 UI)
       ├─ "이 책을 추천드려요" → 도서 정보 (카드 UI)
       └─ "짧은 명상을 해볼까요?" → 호흡/명상 가이드

④ 부가 서비스 (네비게이션으로 접근)
   ├─ 자가 진단 (PHQ-9, GAD-7 등)
   ├─ 커뮤니티 (익명 고민 공유)
   └─ 명상/이완 콘텐츠
```

## 기능 요구사항 상세

### 1. 회원가입 / 로그인

| 항목 | 상세 |
|------|------|
| 회원가입 | 이메일 + 비밀번호 |
| 비밀번호 암호화 | bcrypt 해싱 |
| 인증 방식 | JWT (Access Token + Refresh Token) |
| Refresh Token 저장 | Redis |
| 미인증 접근 | 로그인 페이지로 리다이렉트 |
| 향후 확장 | 소셜 로그인 (Google, Kakao) |

### 2. 오늘의 상태 체크 (Daily Check-in)

매일 첫 접속 시 표시되는 감정/컨디션 체크 템플릿.

**템플릿 구성:**

```
Step 1: 오늘의 기분
┌─────┬──────┬──────┬──────┬──────┬──────┐
│ 😊  │ 😐   │ 😢   │ 😰   │ 😠   │ 😴   │
│좋아요│보통  │우울  │불안  │화남  │지침  │
└─────┴──────┴──────┴──────┴──────┴──────┘

Step 2: 수면 상태
┌──────────┬──────────┬──────────┐
│ 잘 잤어요 │ 보통이요  │ 못 잤어요 │
└──────────┴──────────┴──────────┘

Step 3: 스트레스 수준
┌──────┬──────┬──────┬──────┬──────┐
│  1   │  2   │  3   │  4   │  5   │
│거의  │조금  │보통  │많이  │매우  │
│없음  │있음  │     │있음  │많음  │
└──────┴──────┴──────┴──────┴──────┘
```

**동작:**
- 오늘 이미 체크했으면 스킵 (하루 1회)
- 결과를 DB에 저장 (감정 추적 데이터)
- 결과를 AI 첫 대화의 컨텍스트로 전달

### 3. AI 챗봇 (메인 기능)

| 항목 | 상세 |
|------|------|
| 첫 대화 | 상태 체크 결과 기반 공감 + 탐색 시작 |
| 대화 스타일 | 공감 우선, 비지시적 상담, 한국어 |
| 위기 감지 | 자해/자살 키워드 → 전문 기관 안내 (1393, 109) |
| 대화 저장 | 세션별 DB 저장, 이전 대화 불러오기 |
| 면책 고지 | "AI 상담은 전문 의료 상담을 대체하지 않습니다" |

### 4. 콘텐츠 추천 (멀티모달)

AI가 대화 맥락을 파악하여 적절한 시점에 콘텐츠를 추천한다.

**추천 유형:**

| 유형 | 표시 형태 | 예시 |
|------|----------|------|
| YouTube 영상 | 카드 (썸네일 + 제목 + 링크) | 불안 완화 명상 영상 |
| 도서 추천 | 카드 (표지 + 제목 + 저자) | "마음의 치유" 류 자기계발/심리서 |
| 명상/호흡 | 인라인 가이드 또는 외부 링크 | 4-7-8 호흡법 가이드 |

**동작 방식:**
- LLM이 대화 흐름을 분석하여 추천 시점 판단
- 추천 콘텐츠는 LLM 응답에 구조화된 형태로 포함
- FE에서 카드 UI로 렌더링 (채팅 메시지 내 임베드)

### 5. 라우팅 / 페이지 구조

| 경로 | 역할 | 인증 필요 |
|------|------|----------|
| `/login` | 로그인 | No |
| `/register` | 회원가입 | No |
| `/` | AI 챗봇 (메인) | Yes |
| `/diagnosis` | 자가 진단 | Yes |
| `/community` | 커뮤니티 | Yes |
| `/meditation` | 명상/이완 | Yes |
| `/mypage` | 마이페이지 | Yes |
