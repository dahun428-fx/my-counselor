# 개발 단계별 로드맵

## Phase 1 - MVP (기본 AI 상담 챗봇)

### 목표
AI 챗봇과 대화할 수 있는 최소 기능 제품(MVP) 완성

### FE Agent 작업
- [ ] Next.js 프로젝트 초기화 (Vercel 챗봇 템플릿 기반)
- [ ] 기본 레이아웃 구현 (Header, Sidebar)
- [ ] 채팅 UI 구현 (메시지 입력, 스트리밍 응답 표시)
- [ ] Backend API 연동 설정

### BE Agent 작업
- [ ] Node.js 프로젝트 초기화 (TypeScript, Express/Fastify)
- [ ] PostgreSQL + Prisma 설정
- [ ] 채팅 API 구현 (세션 CRUD, 메시지 전송)
- [ ] LLM 서버 통신 모듈

### LLM Agent 작업
- [ ] FastAPI 프로젝트 초기화
- [ ] LLM API 클라이언트 구현
- [ ] 상담사 시스템 프롬프트 설계
- [ ] 채팅 엔드포인트 (일반 + 스트리밍)
- [ ] 위기 감지 기본 로직

### 산출물
- 동작하는 AI 상담 챗봇 웹앱
- 3개 서버 간 통신 확인

---

## Phase 2 - 핵심 기능 확장

### 목표
사용자 인증, 자가 진단, 대화 히스토리 기능 추가

### FE Agent 작업
- [ ] 인증 UI (로그인, 회원가입, 소셜 로그인)
- [ ] 자가 진단 UI (단계별 질문, 결과 차트)
- [ ] 대화 히스토리 UI (세션 목록, 이전 대화 불러오기)
- [ ] 마이페이지 (프로필, 감정 추적)

### BE Agent 작업
- [ ] 인증 시스템 (JWT, OAuth, Refresh Token)
- [ ] 자가 진단 API (질문지 관리, 결과 저장)
- [ ] 대화 히스토리 저장/조회 최적화
- [ ] 사용자 프로필 API

### LLM Agent 작업
- [ ] 감정 분석 기능
- [ ] 대화 컨텍스트 관리 (이전 세션 요약 활용)
- [ ] 진단 결과 해석 기능

### 산출물
- 회원 기반 개인화된 상담 서비스
- 자가 진단 도구 (PHQ-9, GAD-7)
- 감정 추적 기록

## Phase 3 - 추가 기능

### 목표
커뮤니티, 명상 콘텐츠 등 부가 기능 추가

### FE Agent 작업
- [ ] 커뮤니티 게시판 UI (목록, 상세, 작성)
- [ ] 익명 기능, 공감/댓글 UI
- [ ] 명상/이완 콘텐츠 페이지
- [ ] 오디오/비디오 플레이어
- [ ] 감정 추적 대시보드 (차트)

### BE Agent 작업
- [ ] 커뮤니티 API (게시글 CRUD, 댓글, 공감, 신고)
- [ ] 명상 콘텐츠 API (콘텐츠 관리, 즐겨찾기)
- [ ] 감정 추적 API
- [ ] 알림 시스템 기초

### LLM Agent 작업
- [ ] 대화 요약 기능
- [ ] 토큰 사용량 최적화
- [ ] 프롬프트 개선 및 A/B 테스트

### 산출물
- 풀 기능 웹 애플리케이션
- 커뮤니티 + 명상 콘텐츠

## Phase 4 - 고도화

### 목표
성능 최적화, 모바일 대응, 데이터 분석

### FE Agent 작업
- [ ] 반응형 완전 최적화 (모바일 퍼스트)
- [ ] PWA 지원 (오프라인, 푸시 알림)
- [ ] 접근성 개선 (WCAG 2.1)
- [ ] 성능 최적화 (Core Web Vitals)

### BE Agent 작업
- [ ] API Rate Limiting
- [ ] 로깅/모니터링 (APM)
- [ ] 데이터 분석 대시보드 (관리자)
- [ ] 백업/복구 전략

### LLM Agent 작업
- [ ] RAG 도입 (심리학 지식 베이스)
- [ ] 사용자 히스토리 기반 맞춤 응답
- [ ] 모델 성능 모니터링
- [ ] 비용 최적화

### 산출물
- 프로덕션 레디 서비스
- 모바일 앱 전환 준비 완료
